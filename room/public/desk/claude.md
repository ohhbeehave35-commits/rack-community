# Talkback desk

Do not use this file as the live pack — it has no key.

Open Talkback, pick this desk (or Floor), open Wire, issue a key, and
download the pack (`talkback-lead.md`, `talkback-builder.md`, or
`talkback-reviewer.md`). Drop that file into this Claude Code session.

If the wire is not issued yet, treat a pasted line that starts with RADIO
as a teammate talking to you. Answer in 1–8 sentences. Start with
RADIO to Lead / Builder / Reviewer / All if you need another role.
